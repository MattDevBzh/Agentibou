Les mises à jour Windows s’installent après ton accord ; sur Mac, le téléchargement reste manuel tant que la signature Apple n’est pas configurée.

Les petites
questions.

Tout ce qu’il faut pour bien démarrer.

Comment installer Agentibou sur Windows ?+

Télécharge et lance l’installateur Agentibou pour Windows. Il installe l’application dans ton compte utilisateur et crée un raccourci. Tu n’as pas besoin d’installer Node.js.

Les nouvelles versions se téléchargent dans l’application. Clique sur « Redémarrer pour installer » quand tu es prêt. Depuis une ancienne version ZIP, installe une première fois cette nouvelle distribution et reconnecte tes outils. Tes préférences restent dans %USERPROFILE%\.agentibou (ou le dossier historique .avatai s’il existe).

Lire le guide Windows complet ↓
Et sur Mac ?+

Télécharge la version Apple Silicon, ouvre le DMG (ou décompresse le ZIP) et déplace Agentibou.app dans Applications. Elle est prévue pour les Mac à puce Apple, pas pour les Mac Intel.

Cette bêta n’est ni signée ni notariée. macOS peut donc bloquer son ouverture. Vérifie la provenance du téléchargement avant de l’autoriser dans les réglages de sécurité de ton Mac.

Ça marche avec quels agents ?+

Les sessions locales Codex sont détectées automatiquement. Claude Code et Copilot dans VS Code se connectent depuis Agentibou ; pour VS Code, configure chaque projet et utilise le mode Agent.

Dans Visual Studio, le suivi passe par un outil MCP que l’agent doit appeler : il reste indicatif. Les sessions distantes, WSL, SSH et cloud ne sont pas synchronisées automatiquement.

Est-ce qu’Agentibou envoie mon code quelque part ?+

Agentibou suit les événements localement et n’envoie pas ton code ni tes conversations à un serveur. Il conserve les informations nécessaires au suivi : outil, session, projet, état et heure. La recherche de mises à jour contacte GitHub pour lire les versions disponibles, sans transmettre tes conversations. Le site n’utilise ni outil d’analyse ni cookie publicitaire.

Les règles de traitement des données de tes agents de code restent propres à leurs fournisseurs.

« Terminé », ça veut dire que mon code est bon ?+

Ça veut dire que l’agent a fini sa réponse. Le compagnon célèbre ce moment ; les tests, la revue et la validation du résultat restent à faire.

Je peux mettre les animations en pause ?+

Oui. Agentibou propose des animations réduites et respecte les préférences de ton système. Tu peux aussi masquer chaque compagnon, ou toute l’équipe, depuis l’application.
