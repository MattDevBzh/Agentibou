# Agentibou 0.8.2

- Cinq compagnons inclus dès l’installation : **Vic**, **Paprika** (ex-Toktokette), **Basil** (ex-Toktok), **Tempo** (ex-Bastien) et **Mochi** (ex-Chaton).
- Un bouton **Renommer** sur chaque fiche dans **Compagnons**, pour les personnages inclus comme pour les compagnons importés. Le nom est conservé au redémarrage et actualisé dans les sélections et les fenêtres flottantes.
- Les compagnons auparavant importés deviennent inclus sans doublon et conservent leurs affectations aux outils. Les noms déjà personnalisés sont conservés.
- Les cinq personnages sont également à essayer sur le site.

Sous Windows, chercher une mise à jour dans Agentibou puis cliquer sur **Redémarrer pour installer** lorsque le téléchargement est prêt. Les préférences et compagnons importés sont conservés.

Sur Mac Apple Silicon, télécharger la nouvelle version et copier Agentibou.app dans Applications. Les contrôles stricts des signatures du DMG/ZIP ajoutés en 0.8.1 restent obligatoires. La bêta n’est pas notarifiée par Apple ; une autorisation dans **Réglages Système → Confidentialité et sécurité → Ouvrir quand même** peut être nécessaire après un premier essai d’ouverture.
